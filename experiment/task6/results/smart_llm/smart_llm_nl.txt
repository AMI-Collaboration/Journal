To allocate the tasks for preparing a home workout space, we need to consider both the skills and mass capacity of the available robots. Here's how we can approach this:

### Task Decomposition
1. **Clear the Space**:
   - SubTask 1: Move chairs and tables to the side.
   - SubTask 2: Clear any small items from the floor.

2. **Set Up the Workout Area**:
   - SubTask 3: Place a yoga mat on the floor.
   - SubTask 4: Set up any additional equipment (e.g., dumbbells, resistance bands).

### Task Allocation

#### Step-by-Step Allocation

1. **SubTask 1: Move chairs and tables to the side**
   - Objects involved: ArmChair (28.3 kg), CoffeeTable (11 kg), Chairs (10 kg each)
   - Skills required: `GoToObject`, `PushObject`
   
   **Allocation**:
   - Robot 1 has a mass capacity of 100 kg but lacks `GoToObject` and `PushObject` skills.
   - Robot 2 has all necessary skills (`GoToObject`, `PushObject`) but only a mass capacity of 5 kg.
   
   Since no single robot can handle these objects due to skill or mass limitations, we'll need to form teams or adjust tasks:
   
    For moving heavier objects like ArmChair and CoffeeTable, Robot 2 can be used for pushing since it doesn't require picking up.

2. **SubTask 2: Clear any small items from the floor**
   - Objects involved: Pillow (0.7 kg), RemoteControl (0.15 kg), CellPhone (0.16 kg)
   - Skills required: `GoToObject`, `PickupObject`, `PutObject`
   
    **Allocation**:
    - Robot 4 can perform this task as it has all necessary skills and sufficient mass capacity for these lighter objects.

3. **SubTask 3 & SubTask 4: Set Up the Workout Area**
   - Objects involved: YogaMat, Dumbbell, ResistanceBand
   - Skills required: `GoToObject`, `PickupObject`, `PutObject`
   
    **Allocation**:
    - Robot 4 can handle these tasks as well due to its skill set and ability to manage lighter objects.

### Code Solution

```python
def move_heavy_objects(robot):
    # Move ArmChair
    GoToObject(robot, 'ArmChair')
    PushObject(robot, 'ArmChair')
    
    # Move CoffeeTable
    GoToObject(robot, 'CoffeeTable')
    PushObject(robot, 'CoffeeTable')

def clear_small_items(robot):
    # Clear Pillow
    GoToObject(robot, 'Pillow')
    PickupObject(robot, 'Pillow')
    GoToObject(robot, 'Shelf')
    PutObject(robot, 'Pillow', 'Shelf')

    # Clear RemoteControl
    GoToObject(robot, 'RemoteControl')
    PickupObject(robot, 'RemoteControl')
    GoToObject(robot, 'Shelf')
    PutObject(robot, 'RemoteControl', 'Shelf')

def set_up_workout_area(robot):
    # Place YogaMat
    GoToObject(robot, 'YogaMat')
    PickupObject(robot, 'YogaMat')
    GoToObject(robot, 'Floor')
    PutObject(robot, 'YogaMat', 'Floor')

# Execute Tasks
move_heavy_objects(robots[1])     # Using Robot 2 for heavy object movement by pushing
clear_small_items(robots[3])      # Using Robot 4 for clearing small items
set_up_workout_area(robots[3])     # Using Robot 4 for setting up workout area

# Task to prepare for a home workout is done
```

### Explanation

- **Move Heavy Objects**: Utilizes Robot 2's ability to push heavier objects without needing to lift them.
- **Clear Small Items & Set Up Workout Area**: Utilizes Robot 4's skills and capacity to handle lighter objects efficiently.

This setup ensures that you have a clear and organized space for your home workout while effectively utilizing available robots based on their capabilities. Adjustments may be needed based on specific robot capabilities or additional constraints in your environment.
